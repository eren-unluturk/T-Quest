- 13 stops, not 12: added `place-ccmnl` (Community College) so Charlestown Freedom Trail sites have a nearby stop.
- Coordinates for stops, stores and Freedom Trail sites are approximate (about 50 m); nearest_stop_id was picked by rough distance. Worth a spot check before demo.
- Fictional store addresses are placeholders ("Demo address near X").
- `get_consents` returns only records that exist (no default row per scope); 005 can add defaults if the API should always return both scopes.

- Seed was generated by a one-off script kept outside the repo; JSON files are the source of truth.
- Seed facts were written from memory of well-known history, with Wikipedia/nps.gov source_url values. URLs were not fetched or checked.
