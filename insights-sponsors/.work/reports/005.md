## Deviations
- The 409 policy-mismatch response is not in `openapi/insights-sponsors.yaml` (only 401/422 are). Not changed because the prompt did not ask; the 403 from `require_consent` is also not documented there since no consent-gated route exists yet. Suggest adding both to the draft.
- Revoking a scope that was never granted returns the default row (granted false, null timestamps) without storing anything, so GET still shows null `revoked_at` for it.
- Revoking an already-revoked scope returns the stored record unchanged (keeps the original `revoked_at`).
- Revoke keeps the policy_version of the stored record; the repository's `get_consents` still returns stored records only, and the route fills the defaults per scope.
