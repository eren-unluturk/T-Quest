## Deviations
- The spec in `../contracts/api/` is not published yet, so the draft was used; the contract test prefers the published file automatically once it exists.
- `/predictions` keeps rows with `coalesce(arrival_time, departure_time) >= now()` (prompt said `arrival_time >= now()`), so terminus departures are not dropped.
- `/lines` names: single-route lines use the route long name; multi-route lines derive "<X> Line" from `line-<X>`; all bus routes form one `bus` group.
- Each request opens a short-lived connection (no pool); fine for the hackathon, a pool is a later optimisation.
- Responses validated with `openapi-schema-validator` (OAS 3.0) after inlining `$ref`s, not `openapi-core`.
- Billing: nothing here uses Anthropic API keys or pay-per-usage (AGENTS.md Billing rule). MBTA_API_KEY is the free MBTA key only.
