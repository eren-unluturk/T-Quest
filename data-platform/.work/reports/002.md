## Deviations
- `user_rank` is built on `user_points`, so users with no ledger rows have no row in it (consumers should treat a missing row as rank 1 / 3%). Smallest choice; says so here instead of joining users.
- `route_stops.direction_id` is NOT NULL (it is part of the primary key).
- Tests insert ledger rows for fresh random users and cannot clean them (ledger is append-only); users and consent rows are cleaned up.
- Seed route/stop values are from memory (Park St, Downtown Crossing, South Station, Harvard, Blandford St); coordinates are approximate.
