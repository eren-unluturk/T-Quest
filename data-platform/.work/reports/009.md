- `--cleanup` must delete from the append-only `points_ledger`, so it briefly disables the `points_ledger_no_mutation` trigger and re-enables it in a `finally`. This needs table ownership, which the migration user has.
- Cleanup deletes from `vehicles`/`predictions` including compressed chunks; that needs TimescaleDB 2.11+ (the compose image is latest). Unverified.
- The bench only compresses chunks older than 1 day, so a 1-day run reports ratio n/a.

- Default `--vehicles 600` for 7 days is about 24M rows; extra flags `--vehicles`, `--poll-seconds`, `--runs`, `--out-dir` were added.
- Environment labels are fixed strings (`local`, `tiger_cloud`); the Tiger host is not written anywhere.
- Billing: no pay-per-usage or Anthropic API usage anywhere (AGENTS.md Billing rule).
